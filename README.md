**Lead developer, thirteen years in, working as l'agence Cardona.** The agency builds web
applications end to end — Symfony / API Platform APIs, React and TypeScript front-ends —
adds applied AI where it pays (agents, RAG, OCR, Whisper transcription), and ships them with
Docker and GitLab CI. Past work for EDF, Carrefour, OVH, M6 and TF1.

## Featured work

**[Ponos](https://the-ponos.app/)** *(formerly ticket-runner)* — A team has more tickets
than hands. Ponos hands each one to a Claude Code agent: one task, one isolated session on a
disposable git worktree, and back comes a pull request or a written answer. Several projects
move forward in parallel, in the background, and nothing ships until a human says yes.
Tickets come from its own board or from Notion; code comes back as a GitHub pull request.
<br><sub>Python · Claude Code · git worktrees — [site](https://the-ponos.app/) · [code](https://github.com/SalvadorCardona/ponos)</sub>

**[Leadz](https://leadz.ninja/en)** — B2B prospecting that favours qualified leads over
volume. It finds companies on the web, attaches their website, detects the technologies they
run, rates each site (SEO included), and drives the e-mail campaigns that follow. An MCP
server lets you do all of it from Claude.
<br><sub>Symfony · API Platform · Symfony AI · PostgreSQL · React — [leadz.ninja](https://leadz.ninja/en)</sub>

**[Animalink](https://animalink.io)** — Lead developer, 2023 to 2026, on a B2B SaaS where
animal-care professionals take bookings online. A real product in production, not a demo:
the Symfony / API Platform API, the React front-end, an AI pipeline that reads documents
(OCR) and leaves the result to a human for review, and payments through Stripe Connect.
<br><sub>Symfony · API Platform · React · TypeScript · Stripe Connect — [animalink.io](https://animalink.io)</sub>

**[whisper-desk](https://cardona.digital/whisper-desk/)** — Voice dictation that works
offline, on Linux, WSL and macOS: one shortcut, and the text is typed under the cursor.
Transcription runs on the machine itself, so no audio or text ever leaves it — the point
for any company careful about where its data goes.
<br><sub>Whisper · Python — [documentation](https://cardona.digital/whisper-desk/) · [code](https://github.com/SalvadorCardona/whisper-desk)</sub>

**[react-resource-view](https://cardona.digital/react-resource-view/) + [react-data-form](https://cardona.digital/react-data-form/)** —
A whole back office, delivered much faster. Declare a resource and get its CRUD views —
switch a list from table to cards on the fly, the way Notion does — and its forms, driven
by data rather than hand-written. They work with any API (API Platform, Strapi, Supabase,
FastAPI…) and run in production on several professional projects, Animalink among them.
<br><sub>React · TypeScript — [playground](https://cardona.digital/react-resource-view/playground) · [react-resource-view](https://github.com/SalvadorCardona/react-resource-view) · [react-data-form](https://github.com/SalvadorCardona/react-data-form)</sub>
