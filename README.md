I build web applications end to end — structured APIs, typed React front-ends, and
the tooling that lives around them. Thirteen years of it. Lately I spend a lot of
time on agents and desktop tools wired to real APIs, not to demos.

### Libraries

A small, deliberate set of TypeScript packages for JSON-LD / Hydra APIs — a typed
[client](https://github.com/SalvadorCardona/jsonld-api-client),
[repositories](https://github.com/SalvadorCardona/jsonld-repository),
[item helpers](https://github.com/SalvadorCardona/jsonld-item), a
[metadata registry](https://github.com/SalvadorCardona/resource-registry) — and the React
layer on top: [data-driven forms](https://github.com/SalvadorCardona/react-data-form),
[CRUD views](https://github.com/SalvadorCardona/react-resource-view),
[JWT sessions](https://github.com/SalvadorCardona/react-jwt-session),
[mini-i18n](https://github.com/SalvadorCardona/react-mini-i18n),
[SSR-safe storage](https://github.com/SalvadorCardona/ssr-safe-storage).

### Things I've shipped

**[whisper-desk](https://github.com/SalvadorCardona/whisper-desk)** — Offline voice
dictation for Linux, WSL and macOS. One shortcut, an overlay, and the text is typed
straight under your cursor while you speak. Nothing leaves the machine.
· **[Documentation](https://cardona.digital/whisper-desk/)**

**[ticket-runner](https://github.com/SalvadorCardona/ticket-runner)** — Your Notion
tickets, played by Claude Code: one session per ticket, a pull request at the end. It
runs in the background across all your projects at once, and never touches your working
copy — every ticket gets a disposable git worktree of its own.

**[gnome-claude-usage](https://github.com/SalvadorCardona/gnome-claude-usage)** — A GNOME
Shell indicator for Claude Code usage: a pie in the top bar for the current window,
limits and reset times on click. Reads the official figures — no API key, no token spent.

**[Mobile Factory](https://github.com/SalvadorCardona/mobile-factory)** — A 2D factory
game you play with your thumb, in the browser. Infinite chunked map, a fixed 20 TPS
loop rendered at screen rate, and materials carried building to building by units that
actually walk the distance. TypeScript and PixiJS v8.
· **[Play it](https://cardona.digital/mobile-factory/)**

Also online: **[Trader IA](https://trader.cardona.digital/)**, a paper-trading arena where
several LLM agents each take €1,000 to the S&P 500 and are scored against one another ·
**[Dés 3D](https://salvadorcardona.github.io/des-3d/)**, a physics dice roller running on
web, iOS and Android from a single codebase.
